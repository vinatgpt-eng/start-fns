# СТАРТ ФНС

Демонстрационный одностраничный прототип проекта **«СТАРТ ФНС»** — цифрового помощника адаптации и наставничества сотрудников в первые 90 дней работы.

## Что находится в репозитории

- `index.html` — весь сайт в одном файле: HTML, CSS и JavaScript встроены внутрь.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

Сайт не требует базы данных, Python, PHP или сборщика и готов к публикации как статический GitHub Pages-сайт.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `start-fns`.
2. Загрузите в корень репозитория файлы `index.html` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Укажите ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Через несколько минут GitHub покажет адрес сайта вида:
   `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/start-fns/`

## Важно

Это демонстрационный прототип, а не официальная информационная система ФНС России.

Текущий чат внутри прототипа работает только как интерфейсная демонстрация в браузере. Для реального обмена сообщениями между разными пользователями потребуется серверная часть, аутентификация, база данных и защищённая инфраструктура.
